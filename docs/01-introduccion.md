# Guía 1 - Mi propio caso de negocio

## Datos del negocio

- Nombre del negocio: Comercial JBC
  -Quíen lo dirige:Maricruz Zapata

## Situación actual

La base de datos deventas es un cuadernillo concon todos los anotes del dia se hace un ajuste por semana del cuadernillo de los artefactos vendidos.

## Problema

No existe registro o control de equipos o artefactos vendidos, las cantidades totales, de ventas, los faltantes, las utilidades.

## Lo que necesita

Que se tenga un registro de las cantidades vendidas, los en stok, que muestre los productos de promocion clientes frecuentes, crear nuevos productos.

### Mi caso propio

Sra. Maricruz Zapata tienen el problema de que no existe un control real de cuantos productos se venden, quienes vendieron, un sistema contable de ventas diarias, semanal, mensual , lo cual permita a cualquiera de los proveedores registrar las ventas desde un celular o tableta.
Una solución exitosa debería generar un trabajo mas prolijo, tener ajuste de ventas diarias, semanal, mensual,cantidad de productos vendidos y registrados.
