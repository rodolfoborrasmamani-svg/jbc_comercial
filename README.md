# Sistema de Ventas — Comercial JBC

Sistema web para registrar productos, clientes y ventas,
desarrollado como proyecto del curso Full Stack Básico.

## Tecnologías - HTML5, CSS3, JavaScript (ES6+) - Supabase (PostgreSQL, Authentication)

## Estructura del proyecto

- docs/: documentación del proyecto (requerimientos, historias, etc.) - diagramas/: diagramas del curso - pages/: pantallas del sistema - css/: estilos - js/: lógica y conexión con Supabase - assets/: imágenes e íconos

## Estado del proyecto

En desarrollo (curso Full Stack Básico, Guía 8 de 24).
